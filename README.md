# ECHO HUNT

スマートフォンとイヤホンで遊ぶ、立体音響のホラーゲームです。
見えない敵を足音や呼吸で探し、体を向けてタップで撃破します。

## 遊び方

1. スマホでHTTPSのゲームURLを開き、イヤホンを装着する。
2. ステージと難易度を選び、「準備する」を押す。
3. 「音声を接続して足音を聴く」で右側の足音を確認し、「スマホのセンサーを接続」で利用を許可する。
4. スマホを顔の正面に持ち、「ゲーム開始」を押す。3秒の合図の後に始まる。

音の方向に体を向け、画面をタップして攻撃します。一時停止や設定の操作は攻撃になりません。

- **イージー**：ゲージが満ち、合図が鳴ってから攻撃する。
- **ノーマル**：ゲージやロックの合図はなく、音で方向を判断して攻撃する。空振り後は650ms、命中後は250ms攻撃できない。

敵が近づくと心音が鳴り、攻撃直前には唸り声が聞こえます。予告中でも倒せます。
開始ライフは3。敵の攻撃で1減り、0になるとゲームオーバーです。

## ステージ

| ステージ | 内容 |
|---|---|
| 第一夜・洋館 | 足音で近づく敵と、呼吸しながら回り込む敵 |
| 第二夜・閉ざされた廊下 | 沈黙する敵と、同じ場所で3歩を繰り返す偽の足音 |
| 第三夜・開かずの間 | ボス「屋敷の主」。鍵の音が止まり、息を吸う隙に攻撃する |

第一夜・第二夜は各3ウェーブ・計9体。全ウェーブ終了時にライフが残っていればクリアです。
第三夜はボスに3回命中させるとクリアです。
第一夜・第二夜をクリアすると、難易度を問わず次の夜が解放されます。

練習は「静かな気配」「さまよう気配」「近づく足音」の3種類で、最初から選べます。各60秒です。

最高得点とクリア履歴はステージ・難易度別に、音量・振動・BGM設定とともにブラウザ内へ保存します。
BGMはタイトルと結果画面で流れ、右上のボタンで切り替えます。振動は対応端末のみです。

## 開発

Node.js 24以上とnpmが必要です。WindowsのPowerShellでは、プロジェクトのルートで次を実行します。

```powershell
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --port 5174
```

[http://127.0.0.1:5174/](http://127.0.0.1:5174/)を開きます。

### PCで確認する

[http://127.0.0.1:5174/?debug=1](http://127.0.0.1:5174/?debug=1)を開き、準備画面で「PCのスライダーで試す」を選びます。
音声を接続して「ゲーム開始」を押してください。

- スライダー：向きを変更
- クリック・Space：攻撃
- Esc：一時停止

開発用URLでは敵の角度・距離・状態も表示します。音響・センサーのテスト画面は `?page=audio` で開けます。

### スマホで確認する

HTTPSで配信したゲームを使います。PCのLANアドレスをHTTPで開くだけでは方向センサーは使えません。
センサーの許可や音の定位は、[実機確認手順](docs/PLAYTEST.md)に沿って確認してください。

### テスト・ビルド

```powershell
npm.cmd test
npm.cmd run lint
npm.cmd run build
```

ビルド結果は `dist/` に出力します。

## ファイル

```text
src/components/  画面・スタイル
src/game/        戦闘・ステージ・記録
src/audio/       立体音響・効果音・BGM
src/sensors/     方向センサー
src/debug/       音響・センサーのテスト画面
tests/           自動テスト
```

戦闘処理は `src/game/GameEngine.ts`、敵の設定は `src/game/enemies.ts` にあります。
ステージは `src/game/stages/` で定義し、`src/game/stages.ts` に登録します。

- [戦闘仕様・ステージ追加・担当範囲](docs/COMBAT_DESIGN.md)
- [実機確認手順](docs/PLAYTEST.md)
- [追加BGM・SEの出所と再生成方法](docs/AUDIO_ASSETS.md)

## デプロイ

DockerでNode.js 24のビルドを実行し、Nginxの8080番ポートで配信します。
Google Cloud CLIの対象プロジェクトを確認してから、開発サービスを更新します。

```powershell
gcloud config get-value project
gcloud run deploy echo-hunt-dev --source . --region asia-northeast1 --allow-unauthenticated --port 8080 --min-instances 0
```
