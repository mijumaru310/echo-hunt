# 実機プレイテスト

## 準備

- HTTPSの開発版をスマホで開く。PCではlocalhostでスライダー操作が使える。
- イヤホンを装着。スマホを顔の正面に持ち、体ごと向きを変える。
- 最初は「練習・静かな気配」で確認する。
- 最初はEASY、その後にNORMALへ切り替え、同じステージで違いを確認する。
- 「音声を接続」ボタンで右側から足音が聞こえることを確認する。
- 「スマホのセンサーを接続」で必要な許可を与え、少し動かして「接続済み」になることを確認する。
- iPhone SafariとAndroid Chromeでそれぞれ確認する。実際の使用端末とイヤホンを記録する。

## 確認項目と期待する結果

| 操作 | 期待する結果 |
|---|---|
| 音声・方向入力を接続する前に開始しようとする | 開始ボタンが無効 |
| 開始する | 3、2、1の合図。合図中に敵は接近しない |
| 左右・後方を向く | 音の相対方向がすぐに変わる。敵の位置は画面に出ない |
| スマホを縦持ちから水平寄りへ傾ける | 通常の持ち方の範囲で方位が大きく飛ばない |
| 気配を正面に捉える | 円形ゲージが約0.7秒で満ち、ピッと鳴る |
| ロック途中で向きを外す | ゲージが減り、範囲外のタップで倒せない |
| ロック後にタップする | 命中音、方向付き消滅音、撃破表示、加点。対応端末は振動 |
| 撃破直後に連打する | 1体分だけ加点。次の足音が即座に割り込まない |
| 連続で倒す | CHAINが増え、25点ずつ最大100点の追加ボーナス |
| 接近する敵を倒さず待つ | 心音が鳴り、直前に唸り声。攻撃でライフが1減る |
| 唸り声の間にロックしてタップする | 攻撃前に倒せればライフは減らない |
| 攻撃した敵を放置する | 離脱し、同じ敵から繰り返しダメージを受けない |
| ライフ0にする | 終了音の後、結果画面。リトライでライフ・得点・敵を初期化 |
| 第一夜を進める | 3ウェーブ・計9体。全出現が終わりライフが残ればクリア |
| 一時停止して10秒待つ | 時間・敵の位置・ロック進捗が進まない。音も止まる |
| 停止中に正面を再設定する | 見ている背景と敵の相対方向を保って再開できる |
| カウントダウン中に停止し、再開する | 3秒の合図をやり直し、その後に戦闘開始 |

| センサーが途絶える・計算できない姿勢を長く保つ | 5秒経過で停止と再接続案内。PC操作へ切り替えも可能 |
| 音量・振動設定を変更 | 反映され、次回も設定を保持 |
| 再読み込みして同じステージを選ぶ | ベスト得点とクリア履歴を保持 |
| EASYで気配を捉える | 従来のゲージと合図音。ロック時だけ攻撃できる |
| NORMALで体を回す | ゲージ・色・文言・ボタン状態から敵の方向が分からない。ロック合図音も鳴らない |
| NORMALで音の方向を狙い、待たずに攻撃 | ±15度以内なら即座に撃破 |
| NORMALで空の方向へ攻撃 | 空振り音・表示。650ms攻撃できず、連続撃破が途切れる。ライフは減らない |
| 空振り後に連打 | 隙を延長せず、無効な連打を攻撃回数に加算しない |
| 第二夜の足音が止まるのを待つ | 短い呼吸→沈黙。敵は同じ位置で停止し、その後に再び歩く |
| 沈黙している位置へ攻撃 | NORMALならその瞬間に撃破。EASYはロックして撃破 |
| 第二夜の残響を聞く | 同じ強さの3歩→長い間。近づかず、呼吸もしない |
| フェイクの方向にNORMALで攻撃 | 空振り。撃破数も得点も増えない |
| 本物を倒す | フェイクと怪異の物音が止まり、撃破音を聞ける |
| 異なる難易度で得点を記録 | EASYとNORMALのベストが混ざらない。以前の記録はEASYに残る |
| 保存が禁止されたブラウザで遊ぶ | 保存できなくてもゲームは継続 |

## 第三夜・ボス戦

| 操作 | 期待する結果 |
|---|---|
| 第三夜を開始 | 屋敷の主が1体出現し、体力3を表示。鍵の音が聞こえる |
| 鍵が鳴っている間にノーマルで狙って攻撃 | 「弾かれた」。体力は減らず、短い隙になる |
| 鍵が止まり、息を吸う音の方向に攻撃 | 体力3→2。50点、命中音、振動。まだ撃破数は増えない |
| 同じ隙に連打 | 複数ダメージが入らない |
| ボスが立て直すのを待つ | 別の方向から再び鍵の音。命中ごとに周期が少し短くなる |
| 隙を逃して待つ | 予告後にライフが1減る。ボスは逃げず、戦闘が続く |
| 隙の途中で一時停止して再開 | 体力と隙の残り時間を維持し、呼吸音が復帰 |
| 3回命中させる | 1体撃破、合計1100点。消滅音の後にクリア画面 |
| 最後の撃破後に連打 | 空振りや攻撃回数を追加せず、クリアを待つ |
| 放置する | ボスが離脱してクリアにはならず、ライフ0で敗北 |

ノーマルで隙が開いても、照準の色や文言から狙い目が分からないことも確認します。

## 音について記録する

- **発見**：前後左右を聞き分けられたか。方向を探すために少し回転すると改善したか。
- **敵の違い**：重い足音、速い足音、呼吸音を聞き分けられたか。
- **撃破**：画面を見なくても「倒した」と分かったか。次の敵との間を感じられたか。
- **被弾**：撃破音と間違えなかったか。心音や予告音が足音を隠していなかったか。
- **遅延**：回転と音の変化が一致したか。有線とBluetoothで違いがあるか。

通常プレイの方向は隠したまま評価します。不具合の再現時のみ `?debug=1` で角度・距離・状態を確認します。
振動非対応の端末では、振動しないこと自体は不具合ではありません。
