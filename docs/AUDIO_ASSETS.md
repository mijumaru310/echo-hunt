# 追加したBGM・SEの出所

## 今回の追加・変更分

外部サイトの音源・録音・楽曲・声・リバーブ素材は使用していません。
正弦波、独自の音の配列、疑似乱数ノイズ、短い遅延処理から、このプロジェクト用に生成しています。
外部素材のダウンロードやサンプルの流用がないため、今回の生成分に第三者素材のクレジット表記・利用許諾条件はありません。

| 音 | 実体・生成元 | 用途 |
|---|---|---|
| 洋館のテーマ | `public/sounds/original/mansion-theme.wav` / `src/audio/menuMusic.ts` | タイトルと結果画面の24秒ループ。低音の持続音と不穏な鐘 |
| ロック合図 | `src/audio/cues.ts` の `lock-ready` | イージーで攻撃可能になったときの短いガラス音 |
| 命中・消滅・攻撃予告・被弾 | `src/audio/cues.ts` | 打撃、怪異の息、うなり、低い衝撃。既存の合成音を再設計 |
| 波開始・クリア・敗北・カウントダウン | `src/audio/cues.ts` | 鉄の鐘、低い余韻、崩れる音、乾いた打音。既存の合成音を再設計 |
| ノック・囁き・扉・ボス等 | `src/audio/cues.ts` | 従来の自作合成SEを継続使用 |

BGMの再生成にはNode.js 24以上で以下を実行します。

```powershell
node --experimental-strip-types scripts/generate-audio.mjs
```

SEはゲームの音声接続時にWeb Audioのバッファとして生成・キャッシュします。
定位に関わる足音・ロック・ボスの鍵と呼吸は、追加の反響を付けず聞き分けを保ちます。

## 再生方針

- BGMは最初のタッチまたはEnter/Space操作で再生を開始します。右上のボタンでオン・オフを切り替え、設定をブラウザに保存します。
- 準備画面、カウントダウン、プレイ中、一時停止画面ではBGMを止めます。
- 足音、呼吸、偽物のリズムがゲームの判断材料のため、戦闘中はSEと既存の環境音を使用します。
- 別タブや画面非表示ではBGMを停止します。BGMを再生できなくてもゲームの音声接続は妨げません。
